GitHub Actions

Trigger PDF builds from GitHub.

The workflow compiles every template with user-resources/linkedin-profile.json and uploads PDFs as short-lived artifacts.

  1. Open the repository on GitHub.
  2. Go to Actions.
  3. Select Build Sample PDFs.
  4. Click Run workflow.
  5. Keep branch main and start the run.
  6. Download PDFs from Artifacts.

Backend Trigger

Run CI from this page.

The page calls your Cloudflare Worker backend. The GitHub token stays on Cloudflare, and this page only sends the private CI trigger key.

Backend URL https://noob-resume-ci-trigger.ray9090.workers.dev Use the same CI_TRIGGER_KEY value you added with wrangler secret put CI_TRIGGER_KEY. Do not enter your GitHub token here.

Enter your CI_TRIGGER_KEY and click Trigger CI.
